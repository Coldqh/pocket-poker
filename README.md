# POCKET — poker club & academy

Бесплатный тренажёр техасского холдема на условные фишки. Цель — сделать удобную игру и системный курс покерной стратегии.

## Первая версия

- Свободная игра один на один с ботом
- Основы правил и стратегии в интерактивной академии
- Локальная статистика и сохранение прогресса
- Адаптивный интерфейс

## Публикация

Включите GitHub Pages в **Settings → Pages → Build and deployment → Deploy from a branch → main / (root)**. Адрес приложения: https://coldqh.github.io/pocket-poker/

Это учебный симулятор без игры на деньги и без обещаний гарантированной прибыли. В дальнейшем планируется переход на React + TypeScript и более глубокая аналитика.
