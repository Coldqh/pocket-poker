# POCKET ♠ · 0.2

Бесплатный локальный покерный клуб и персональный учебный тренажёр. Только условные фишки, без ставок и платежей.

## Что работает

- Тёмное главное меню с быстрым переходом к игре, обучению и статистике. Адаптивный интерфейс для телефона и компьютера.
- **Texas Hold'em на 2–6 человек:** ты и от 1 до 5 ботов, раздача из одной колоды, блайнды, смена дилера, все улицы торгов, чек/колл/фолд/рейз, олл-ины, сайд-поты, определение лучшей пятикарточной комбинации из семи.
- После каждой руки кнопка «Следующая раздача» продолжает тот же матч, сохраняет стеки и оставшихся игроков. Если стек закончился, показывается конец матча — меню не открывается само. Можно начать новый матч.
- Текущая раздача сохраняется в `localStorage` после каждого изменения, поэтому можно переключаться между разделами и обновлять страницу.
- **Персональная академия:** анкета о текущих знаниях и интересах, приоритет интересных тем, свободный выбор направлений, несколько блоков теории перед практикой и разборы контекстных игровых ситуаций с картами и вариантами решений.
- 8 направлений, 16 игровых задач, локальный прогресс и результаты повторений.
- PWA с офлайн-доступом после первого посещения, автоматическая публикация на GitHub Pages через Actions.

## Запуск

Node.js 22+:

```bash
npm install
npm run dev
```

Проверки и сборка:

```bash
npm test
npm run build
```

## GitHub Pages

Открыть `Settings → Pages → Build and deployment → Source → GitHub Actions`. После push в ветку `main` workflow `.github/workflows/deploy.yml` устанавливает зависимости, запускает тесты, собирает `dist` и публикует его. База ресурсов Vite указана как относительная `./`.

Предполагаемый адрес этого репозитория: https://coldqh.github.io/pocket-poker/.

## Ограничения

- **Это прототип, не валидированный покерный солвер.** Поведение ботов эвристическое и специально упрощено. Они не видят закрытые карты других игроков, но не умеют полноценно адаптироваться к диапазонам.
- Никаких реальных ставок, казино, покупки фишек или гарантий прибыли нет.
- Нет онлайнового мультиплеера, собственной серверной базы, пользовательской синхронизации, ICM-солвера, GTO-решателя или расчётов EV для раздач в реальном времени.
- Прогресс хранится локально и стирается при очистке данных сайта. Формат сохранения v2 отличается от версии v1, старый матч автоматически не переносится.
- Матчи против нескольких ботов — это обычный локальный стол, ещё не полноценная турнирная сетка.
