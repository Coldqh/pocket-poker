# POCKET ♠

Бесплатный обучающий покерный клуб. Публичный прототип, без реальных ставок.

## Уже работает

- **Игра:** честная 52-карточная колода, хедз-ап No-Limit Texas Hold'em против бота; смена баттона и блайндов, префлоп/флоп/тёрн/ривер, чек/колл/фолд/рейз, олл-ин и вскрытие.
- **Комбинации:** оценка лучших пяти карт из семи, от старшей карты до стрит-флеша, с разрешением ничьих.
- **Академия:** 6 коротких уроков с проверкой знаний.
- **Статистика:** результаты текущего матча, локальное сохранение игры и уроков.
- **PWA:** приложение можно установить, основной функционал работает офлайн после первого посещения.

## Запуск

Требуется Node.js 22+.

```bash
npm install
npm run dev
```

Для проверки сборки:

```bash
npm run build
```

## Публикация на GitHub Pages

1. Создай **публичный** репозиторий `pocket-poker` на GitHub.
2. Загрузи в репозиторий содержимое этой папки, включая `.github/workflows/deploy.yml` (не ZIP-файл целиком).
3. В **Settings → Pages → Build and deployment → Source** выбери **GitHub Actions**.
4. Вкладка **Actions** покажет деплой; после завершения сайт откроется по адресу `https://<username>.github.io/pocket-poker/`.

Сборка использует относительные URL ресурсов и корректно работает в подкаталоге GitHub Pages.

## Важно

- Это **учебная альфа**, а не полноценный профессиональный покерный симулятор.
- Бот использует простую эвристическую стратегию, не GTO и не «покерный ИИ».
- Нет мультиплеера, облачной синхронизации, нескольких форматов или профессиональной аналитики EV.
- Статистика хранится **только на текущем устройстве**. Очистка данных браузера удаляет прогресс.
- В приложении **нет реальных денег**, казино, вывода средств, депозитов и покупок фишек.
